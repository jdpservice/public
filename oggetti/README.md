# Oggetti pubblici

Inserisci qui i file che vuoi rendere pubblici (immagini, PDF o altri documenti).

Dopo il caricamento nel repository `jdpservice/public` e l'attivazione di GitHub Pages, il link di un file sarà:

`https://jdpservice.github.io/public/oggetti/NOME-FILE.ESTENSIONE`

Esempio: `brochure.pdf` → `https://jdpservice.github.io/public/oggetti/brochure.pdf`

Il repository è pubblico: carica qui solo file che vuoi rendere accessibili a chiunque.
